CAMBRIAN QUILL

Sixteen complete book designs for the student anthology — front, spine and back for every one. Ten are built from original photography, six are drawn entirely in code. All are set at full print size, A5 with bleed. Drag any cover sideways to turn the book: front → spine → back.

Handmade design by Gurkaran · designed and assembled on Canva

“Sixteen covers, one book. Pick the one that feels like the story.” — Gurkaran

Set one · photographic

Ten covers built on real photographs, chosen from a library of ninety-six and then cropped, graded and typeset by hand for this book.

Set two · built with Jarvis

The original six, made with Gurkaran’s own AI assistant, Jarvis. There is no photograph anywhere in these — every ridge, bird, ring and gradient is drawn in code, shape by shape. They came first, and they set the direction everything else followed.

A few things we’d like to know

  • Which one is closest? Closest, not perfect — everything else stays open once you pick.
  • Photographic, or drawn? Set one or set two. This single answer settles most of what is left.
  • Is the back cover text right? Swipe to the back of any book to read it. The credits and blurb can all change.
  • Where should the school logo sit? A slot is already reserved on every back cover, next to the barcode.
  • How many pages will the book run to? The spine is set at a provisional 12mm. The printer’s page count fixes it exactly.
  • Printing details, when convenient Finished size, binding, who is printing, and the date you need it by.
