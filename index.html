TRAVERSE

Sixteen cover designs for the student anthology, in two sets — ten built from original photography, and six drawn entirely in code. All of them are set at full print size, A5 with bleed, ready for press. Tap any cover to see it larger.

Handmade design by Gurkaran · designed and assembled on Canva

“Sixteen covers, one book. Pick the one that feels like the story.” — Gurkaran

Set one · photographic

Ten covers built on real photographs, each chosen from a library of ninety-six and cropped, graded and typeset by hand for this book.

Set two · built with Jarvis

The original six, made with Gurkaran’s own AI assistant, Jarvis. There is no photograph anywhere in these — every ridge, bird, ring and gradient is drawn in code, shape by shape. They came first, and they set the direction everything else followed.

A few things we’d like to know

  • Which one is closest? Closest, not perfect — everything else stays open once you pick.
  • Photographic, or drawn? Set one or set two. This single answer settles most of what is left.
  • Should students appear on the cover? Some show figures and silhouettes; others are landscape only.
  • Where should the school logo sit? It can be added to any of these — top, bottom, or beside the school name.
  • Is the wording final? Title, subtitle and the school credit line, before artwork is locked.
  • Printing details, when convenient Finished size, page count, who is printing, and the date you need it by.
